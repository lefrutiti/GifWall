# GifWall

[English](README.md) · **Русский**

Живые обои для macOS: видео и анимированные GIF на рабочем столе и экране блокировки.

GifWall живёт в строке меню. Перетащите в него видео, GIF или ZIP-архив, и файл появится в
**Системные настройки → Обои** рядом с обоями Apple. Там же можно переключаться между всеми добавленными.
Экран блокировки и заставку проигрывает сама macOS, а анимацию на рабочем столе рисует GifWall.

## Возможности

- **Форматы:** MP4, MOV, M4V (H.264, HEVC, ProRes), GIF, WebP, APNG, HEICS и ZIP-архивы с ними
  (в том числе проекты Wallpaper Engine типа *video*).
- **Библиотека в Системных настройках:** каждый добавленный файл — отдельные обои в разделе «GifWall».
  Выбирать можно там или в панели в строке меню.
- **Экономно расходует ресурсы:** файл один раз конвертируется в HEVC, который декодирует видеочип, под размер
  самого большого монитора и не больше 30 кадров в секунду. Анимация ставится на паузу, когда рабочий стол закрыт окнами,
  экран спит или Mac переключён на другого пользователя.
- **Не оставляет следов:** при удалении (в Корзину или через `uninstall.sh`) обои GifWall пропадают из Системных настроек,
  а на место возвращаются те, что стояли до него.

## Требования

- macOS 14 Sonoma или новее, Mac на Apple silicon.
- Анимированный экран блокировки — macOS 26. В более ранних версиях там будет неподвижный кадр.
- Для сборки: Xcode или Command Line Tools (`xcode-select --install`). Других зависимостей нет.

## Установка

```sh
git clone https://github.com/lefrutiti/GifWall.git
cd GifWall
./build.sh --install    # собирает GifWall.app, копирует в «Программы» и запускает
```

Приложение подписано без сертификата разработчика, поэтому при первом запуске macOS может сообщить, что не может
проверить разработчика. Откройте его через правый клик → **Открыть** или разрешите запуск в
**Системные настройки → Конфиденциальность и безопасность**.

Просто `./build.sh` собирает `build/GifWall.app` без установки.

## Как пользоваться

1. Нажмите на значок в строке меню и перетащите файл на панель (или нажмите **Добавить…**,
   или выберите в Finder *Открыть в программе → GifWall*).
2. Файл сконвертируется и станет обоями. Переключаться можно в панели или в
   **Системные настройки → Обои → GifWall**.
3. Правый клик по обоям в панели — переименовать или удалить.

Переключатель вверху панели включает и выключает анимацию рабочего стола. **Запуск при входе** держит GifWall
запущенным после перезагрузки. Когда GifWall не запущен, на рабочем столе неподвижный кадр, а экран блокировки
всё равно анимирован.

## Удаление

Переместите GifWall в Корзину, пока он запущен, или выполните:

```sh
./uninstall.sh
```

В обоих случаях его обои пропадут из Системных настроек и вернутся ваши прежние.

## Как это устроено

macOS анимирует только собственные видео-обои Apple (Aerials). GifWall регистрирует каждое видео как Aerial в
пользовательском списке обоев (`~/Library/Application Support/com.apple.wallpaper`) и выбирает его в настройках обоев.
Это недокументированный механизм, и обновление macOS может его сломать.

Плеер экрана блокировки требует HEVC с временными слоями, как у роликов Apple, иначе после первой разблокировки видео
замирает. Поэтому видео кодируются через VideoToolbox с такими слоями (см. `LayeredHEVCWriter.swift`).

## Windows

В папке `Windows/` лежит отдельное приложение для Windows 10/11: значок в трее и обои на рабочем столе через libmpv.
Библиотеки там нет, обои одни. Собирается с .NET 10 SDK:

```sh
cd Windows && ./build.sh    # результат: Windows/dist/GifWall.exe + libmpv-2.dll
```
